Amazon :
--------

-> When we retrieve amazon jobs through sort by recent, it is sorted by the job created date in ascending order not by job updated date.

You can observe this via amazon_jobs.json file which the scraper retrieves from amazon's career website.







Nutanix Warm-Up:
----------------

Headless helper at `scripts/nutanix_cookie_warmup.py` will spin up Playwright,
solve the consent banner, and print a valid `Cookie` header. Run locally with:

	python scripts/nutanix_cookie_warmup.py --output nutanix_cookie.txt

Remember to install Playwright first (`pip install playwright` followed by
`playwright install chromium`). Copy the printed header into the
`NUTANIX_COOKIE` environment variable before deploying to Lambda.





Cisco Widgets API:
------------------

Set the following environment variables (or Lambda secrets) before running the
new `cisco` scraper:

	CISCO_COOKIE		Optional full `Cookie` header copied from DevTools (PLAY_SESSION + Optanon tokens).
	CISCO_CSRF_TOKEN	Optional `x-csrf-token` value that pairs with the session cookie.
	CISCO_COUNTRIES		Pipe- or comma-separated country filters (default: "United States of America").
	CISCO_PAGE_SIZE		Page size for each widget request (default: 50).
	CISCO_MAX_PAGES		Maximum number of paginated requests (default: 40).
	CISCO_KEYWORDS		Optional keyword search string.

The scraper posts to `https://careers.cisco.com/widgets`, so the session token
must grant access to the jobs API if the endpoint enforces CSRF or session
checks.
